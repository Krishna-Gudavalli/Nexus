# 🧠 NEXUS AI Specialist Roles

NEXUS presents its core agents by **job function**, not by the underlying provider or model.

## 🔎 Researcher AI
**Purpose:** Research & repository intelligence.
- Investigates repositories and documentation.
- Gathers evidence and context.
- Separates facts from assumptions.
- Prepares context for security analysis or remediation.

## 🛡️ Security AI
**Purpose:** Vulnerability detection & analysis.
- Finds security weaknesses.
- Explains evidence and severity.
- Identifies likely attack paths.
- Recommends safe remediation.

## 🔧 Fixer AI
**Purpose:** Remediation & patch generation.
- Turns validated findings into focused changes.
- Proposes minimal, testable patches.
- Explains diffs and remediation decisions.
- Works with the approval/PR pipeline.

## 🔀 AI Gateway
OmniRoute, OpenAI, Gemini, OpenRouter, Anthropic, and Ollama are **providers/routing infrastructure**, not agent identities. The UI keeps provider/model details in the technical model-routing area while agent responses are labeled by specialist role.
